搜尋策略不是按一下就自動長好的成品。
搜尋策略需要使用者／研究者理解問題、照料每個概念，再逐步發展、檢查與測試。A search strategy isn’t a finished product that grows at a single click.
It needs a user / researcher who understands the question, tends each concept, and develops, checks and tests it step by step.

PICO 檢索策略產生器PICO Strategy Builder

在 PICO 表填入/匯入自由詞彙與控制詞彙，啟動半自動查驗控制詞彙，選欄位快速切換欄位完整度，一鍵生成/匯出各資料庫檢索策略。PubMed API 可以幫助粗估 SR 搜得文章量，或直接做實證精準查。Enter or import free-text terms and controlled vocabulary into the PICO table, run semi-automatic verification of the controlled vocabulary, switch field completeness quickly by choosing fields, and generate / export each database’s strategy in one click. The PubMed API helps you roughly estimate how many records an SR search will retrieve, or run a precise evidence search directly.

資料庫檢索語法轉換器Search Syntax Converter

貼上任一資料庫的檢索式，一鍵轉出各大資料庫／平台語法，可下載 Word。適合手上已經有第一個資料庫的搜尋策略者，但是控制詞彙要自理喔！Paste a query from any database and convert it to the major databases/platforms in one click, with Word download. Ideal if you already have a strategy for your first database — but controlled vocabulary is up to you!

3

鄰近字分堆組合器Proximity Builder

把相同概念的多個片語，透過程式判斷自動分堆，再用鄰近字語法組合，兼顧完整與精準度的平衡。整理好可直接送進 PICO 產生器或語法轉換器。Phrases for the same concept are automatically grouped into stacks, then combined with proximity syntax to balance completeness and precision. Send the result straight to the PICO Strategy Builder or the Syntax Converter.

4

PubMed Light ✦

以 PICO 為引導，在 PubMed 逐列建立檢索：輸入檢索詞即提示 MeSH 標目，一鍵帶入同義詞（Entry Terms），可切換欄位、設定鄰近字，並即時顯示 PubMed 筆數。右側可看上下位結構與 See Also。Build a PubMed search row by row, guided by PICO: MeSH headings are suggested as you type, synonyms (Entry Terms) are added in one click, fields and proximity are adjustable, and PubMed counts update live. Broader/narrower headings and See Also are shown alongside.

Happy SearchHen 緣起How Happy SearchHen began

系統性回顧的檢索，常讓人覺得繁瑣又容易出錯。
Happy SearchHen（搜尋策略生成雞）希望把這段過程變得友善一點：
你把同義詞與控制詞彙交給牠，
牠幫你把跨資料庫的檢索策略一顆一顆「生」出來
——穩定、可重現、好覆核。

Searching for a systematic review is often tedious and error-prone.
Happy SearchHen aims to make it a little friendlier:
hand over your synonyms and controlled vocabulary,
and it lays out cross-database search strategies one egg at a time
— stable, reproducible, and easy to double-check.
